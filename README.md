# OAC — Old Ai Chat

> 为老安卓设备打造的 AI 对话应用。从 Android 2.1 到 Android 13，全面兼容。

---

## 📱 兼容性

| 系统版本 | 架构 | 测试状态 |
|---------|------|---------|
| Android 2.1 | ARMv5 | ✅ 通过 |
| Android 2.3 | ARM | ✅ 通过 |
| Android 4.2.2 | - | ✅ 通过 |
| Android 6 | - | ✅ 通过 |
| Android 7 | x86 | ✅ 通过 |
| Android 9 | - | ✅ 通过 |
| Android 10 | - | ✅ 通过 |
| Android 13 | - | ✅ 通过 |

*最后测试日期：2026.8.30*

---

## 🤖 API 支持

- **默认 API**：NVIDIA 免费模型
- **自定义 API**：支持接入任意兼容 OpenAI 格式的 API 平台
- **代理支持**：支持通过代理平台中转

> ⚠️ 公共 API 可能因占用过高导致不可用，建议配置自己的 API Key。

| 特性 | 说明 |

## 🚀 快速开始

1. 下载最新 APK（见 [Releases](https://github.com/shumin1145/Old-Ai-Chat/releases）
2. 安装到设备
3. 在设置中配置 API Key（可选使用默认公共 API）
4. 开始对话！
